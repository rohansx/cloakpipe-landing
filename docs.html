Documentation

Redact PII in your LLM calls in 5 minutes.

CloakPipe is a drop-in proxy for the OpenAI and Anthropic APIs. Point your existing client at it; CloakPipe detects and masks PII in your prompt, forwards the masked request to the model with your own key, then restores the real values in the response. Your sensitive data never reaches the provider in the clear.

Quickstart

1
Create an API key. Sign in at app.cloakpipe.co, open Vault in the sidebar, and click Create key. Copy the cpk_live_… key — it's shown once.
2
Point your client at the proxy. Base URL https://api.cloakpipe.co/v1, with two headers: X-CloakPipe-Key (your CloakPipe key) and Authorization: Bearer (your own OpenAI/Anthropic key, forwarded upstream).
3
That's it. Every call now flows through CloakPipe — PII masked outbound, restored inbound.
curl https://api.cloakpipe.co/v1/chat/completions \
  -H "X-CloakPipe-Key: cpk_live_xxxxxxxxxxxxxxxx" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Email jane@acme.com about invoice #4821"}]
  }'
from openai import OpenAI

client = OpenAI(
    base_url="https://api.cloakpipe.co/v1",
    api_key="YOUR_OPENAI_KEY",                       # forwarded upstream
    default_headers={"X-CloakPipe-Key": "cpk_live_xxxxxxxxxxxxxxxx"},
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Email jane@acme.com about invoice #4821"}],
)
print(resp.choices[0].message.content)
import OpenAI from "openai";

How it works

For every request, CloakPipe runs a layered detection pipeline, masks the matches into reversible tokens, forwards the masked prompt to the provider, then rehydrates the tokens back into the response.

  1. Detect — deterministic regex + checksums, a neural privacy-filter model, and region-specific structured IDs (PAN, Aadhaar, …).
  2. Mask — entities become deterministic, format-preserving tokens the model can still reason about (not dead [REDACTED] blanks).
  3. Forward — the masked prompt goes to OpenAI/Anthropic with your own provider key.
  4. Rehydrate — tokens in the response are swapped back to the real values before they reach you, including streamed responses.

Categories detected include names, organizations, locations, emails, phone numbers, dates, amounts, IPs, URLs, secrets/keys, credit cards, SSNs and more.

Authentication

Base URL: https://api.cloakpipe.co. There are two schemes:

RoutesHeaderUsed by
Proxy — /v1/*X-CloakPipe-Key: cpk_live_…server-to-server integrations
Management — /api/*Authorization: Bearer <session>the dashboard

Proxy calls also pass Authorization: Bearer <provider-key> — your own OpenAI/Anthropic key, which CloakPipe forwards upstream and never stores. CloakPipe keys are stored only as an Argon2 hash + prefix; revoke any key anytime from the Vault.

Proxy endpoints

Authenticate with X-CloakPipe-Key.

POST /v1/chat/completions

OpenAI-compatible chat completions. Masks PII in every message, forwards to the provider (OpenAI for gpt-*/o*, Anthropic for claude-*), then rehydrates tokens in the response. Supports streaming (SSE). The schema matches OpenAI, with an added _cloakpipe metadata block (entities masked, latency).

POST /v1/embeddings

Masks the input text(s) and forwards to the provider's embeddings endpoint.

Management API

Authenticate with the dashboard session (Authorization: Bearer).

Self-host (open source)

The detection engine and proxy are open source (MIT) at github.com/rohansx/cloakpipe. Run it yourself:

# Docker
docker build -t cloakpipe https://github.com/rohansx/cloakpipe.git
docker run -p 8900:8900 -e OPENAI_API_KEY=sk-... cloakpipe

# Or from source
git clone https://github.com/rohansx/cloakpipe && cd cloakpipe
export OPENAI_API_KEY=sk-...
cargo run -p cloakpipe-cli -- start   # proxy on 127.0.0.1:8900

Point your client at http://localhost:8900/v1. The self-hosted core uses regex/heuristic detection; the managed cloud adds the neural privacy-filter model, the encrypted vault, audit logs and team controls.
